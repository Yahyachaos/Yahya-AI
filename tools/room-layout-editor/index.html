Präzise bewegen – Richtung in Meter

X: links/rechts · Y: unten/oben · Z: hinten/vorne (zur Kamera +Z). Schrittweite individuell.

Bearbeitungsverlauf

Änderungen werden zusätzlich lokal im Browser zwischengespeichert. Die heruntergeladene JSON ist die portable Sicherung.

Kamera / Ansicht

Die Referenz-Perspektive ist ein geometrisch geschätzter Kameraversuch, kein optischer PASS und keine Android-Kamera.

Positionen sichern

Speichern enthält die exakten X/Y/Z-Positionen, X/Y/Z-Winkel, Maßstab sowie die Verankerung für alle 13 Objekte. Ein Assembly-Export bleibt ein Kandidat – seine zusätzlichen X-/Z-Winkel benötigen vor einer Android-Übernahme noch einen eigenen Importer. Keine App-Datei wird automatisch geändert.

Modellstatus

Lade Raumdaten…

GLB-Dateien werden unverändert aus dem Repository geladen. Bei Ladefehlern werden Platzhalter angezeigt – damit ist die optische Übereinstimmung nicht bestätigt.
